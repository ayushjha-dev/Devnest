React Server Components (RSC) allow components to render on the server and send only the resulting HTML to the client, dramatically reducing JavaScript bundle sizes. Unlike SSR, RSC can access backend resources directly without APIs. We'll explore the mental model, streaming, suspense integration, and migration strategies. Includes Next.js 13+ App Router examples and performance comparisons showing 40-60% bundle size reductions.
